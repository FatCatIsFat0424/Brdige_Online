# Component: i18n 多語系 (Phase 6)

> **依賴**: `01-lobby-room`、`02-chat`、`03-game-dealing-bidding`、`04-game-playing-scoring`（所有包含使用者面向文字的前端元件）
> **建議順序**: 在所有功能性 UI 完成後（Phase 4 之後），但可與 Phase 5 並行

---

## 概述

為所有前端介面實作中文（zh-TW）與英文（en）雙語切換，使用 react-i18next 框架。

---

## 子任務

### 1. i18n 框架設定

- [ ] 安裝 `react-i18next` 與 `i18next` 依賴
- [ ] 建立 `client/src/i18n.ts` 初始化設定（預設語言 zh-TW、fallback en）
- [ ] 在 `client/src/main.tsx` 中引入 i18n 初始化

### 2. 翻譯檔案 — 繁體中文

#### 2.1 `client/public/locales/zh-TW/translation.json`

- [ ] 大廳頁面文字（暱稱輸入提示、顏色選擇、建立房間、加入房間等）
- [ ] 房間頁面文字（座位名稱 N/E/S/W、準備、取消準備、離開房間等）
- [ ] 遊戲頁面文字（叫牌、pass、出牌提示、你的回合、倒牌重洗提示等）
- [ ] 結算頁面文字（合約、墩數、獲勝、繼續、離開等）
- [ ] 聊天相關文字（發送、訊息輸入提示等）
- [ ] 錯誤訊息文字（房間不存在、座位已滿、暱稱不可為空等）
- [ ] 斷線/重連相關文字

### 3. 翻譯檔案 — 英文

#### 3.1 `client/public/locales/en/translation.json`

- [ ] 所有與 zh-TW 對應的英文翻譯

### 4. 前端元件改造

- [ ] `LobbyPage` 及子元件：所有硬編碼文字替換為 `t()` 呼叫
- [ ] `RoomPage` 及子元件：所有硬編碼文字替換為 `t()` 呼叫
- [ ] `GamePage` 及子元件：所有硬編碼文字替換為 `t()` 呼叫
- [ ] `ChatPanel` 及子元件：所有硬編碼文字替換為 `t()` 呼叫
- [ ] `ScoreBoard`：所有硬編碼文字替換為 `t()` 呼叫
- [ ] `ActionLog`：日誌訊息的 i18n 處理
- [ ] 錯誤訊息：所有 error toast/alert 文字 i18n 化

### 5. 語系切換 UI

- [ ] 建立 `client/src/components/common/LanguageSwitch.tsx` 元件（zh-TW / en 切換按鈕）
- [ ] 在大廳頁面嵌入 LanguageSwitch
- [ ] 在房間頁面嵌入 LanguageSwitch
- [ ] 在遊戲頁面嵌入 LanguageSwitch
- [ ] 語系選擇持久化（localStorage）

### 6. 驗收

- [ ] 所有介面文字可在中英文之間切換
- [ ] 切換語系後即時生效，無需重新整理
- [ ] 語系選擇在重新載入後保留
- [ ] 無遺漏的硬編碼文字
